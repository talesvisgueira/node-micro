# <img src=".github/logo.svg" alt="" width="32"> Sistema de gerenciamento do ciclo de vida de software

[![NPM version](https://img.shields.io/npm/v/@anthropic-ai/sdk.svg)](https://npmjs.org/package/@anthropic-ai/sdk)
